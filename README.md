# ingredia

Помощник в Telegram, который помогает учитывать продукты дома и решать, что приготовить.

## Возможности

- Меню и личный кабинет прямо в Telegram.
- Добавление покупок по фотографии или голосовому сообщению.
- Виртуальный холодильник с количеством продуктов и сроками годности. Расчётные сроки явно
  отмечаются как оценки.
- Подбор блюд по имеющимся продуктам и фотографии холодильника.
- Сохранение понравившихся рецептов в личное избранное.

## Статус

Реализована первая часть MVP: меню и кабинет, холодильник с ручным добавлением,
PostgreSQL и отдельный админ-бот с подтверждаемой блокировкой пользователей.
Покупки добавляются по фото или свободному тексту после проверки списка и подтверждения.
Работают оценочные сроки для поддержанных продуктов, подбор блюд по запасам
и личное избранное. Холодильник показывает шесть компактных кнопок с отдельными карточками.
Продукты с просрочкой больше 30 дней удаляются автоматически.
Голос и сверка фотографии полки с запасами ещё в разработке.
