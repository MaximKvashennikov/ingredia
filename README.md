# ingredia

Помощник в Telegram, который помогает учитывать продукты дома и решать, что приготовить.

## Возможности

- Меню и личный кабинет прямо в Telegram.
- Добавление покупок по фото магазинного чека, фото продуктов или текстом.
- Виртуальный холодильник с количеством продуктов и сроками годности. Расчётные сроки явно
  отмечаются как оценки.
- Подбор блюд по имеющимся продуктам.
- Сохранение понравившихся рецептов в личное избранное.

## Статус

Реализована первая часть MVP: меню и кабинет, холодильник с ручным добавлением,
PostgreSQL и отдельный админ-бот с подтверждаемой блокировкой пользователей.
Покупки добавляются по фото чека, фото продуктов или свободному тексту после проверки списка и
подтверждения.
Работают оценочные сроки для поддержанных продуктов, подбор блюд по запасам
и личное избранное. Холодильник показывает по шесть компактных блоков продуктов на странице.
Сортировка — по сроку годности, неизвестные даты в конце.
❌ удаляет продукт одним нажатием; очистка всего холодильника требует подтверждения.
Оценочные даты подписаны «Примерно до»; при отсутствии правила — «Срок не рассчитан».
Продукты с просрочкой больше 30 дней удаляются автоматически.
Сверка фотографии полки с запасами ещё в разработке.
