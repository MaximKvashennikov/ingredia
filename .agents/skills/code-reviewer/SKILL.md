# Ревью реализации ingredia

Прочитай AGENTS.md и затронутые требования OpenSpec. Просмотри итоговый diff, новые файлы
и связанные вызовы. После исправлений повторно проверь затронутый путь.

Проверь инварианты, await и освобождение ресурсов, повторную обработку и честность сообщений
об успехе. Проверяй права по доверенному ID на каждой команде и старой кнопке; пользовательский
и административный контексты не должны смешиваться.

Проверь разделение адаптеров, схем, промптов и представлений, границы SDK, типы и Google-докстринги.
Ищи лишние ветвления и дублирование; Python-комментарии с # запрещены.
Секреты должны иметь SecretStr и включаться в централизованное маскирование.
Не печатай .env или реальные ключи при проверке.

Для подтверждённого дефекта укажи приоритет, файл/строку, путь воспроизведения и влияние.
Исправляй проблемы текущей задачи без расширения реализации. Не требуй абстракций ради формы.
Запускай только разрешённые проверки: действующий запрет повторных pytest и живых AI-вызовов
сохраняется. Ruff/mypy не доказывают корректность поведения.

Если дефектов нет, сообщи об этом и ограничениях проверки. Собственный проход не называй
независимым ревью. Скилл применяется агентом и сам по себе не устанавливает Git hook.
