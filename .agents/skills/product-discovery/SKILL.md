# Исследование продукта ingredia

Определи продуктовый вопрос и границы рынка: виртуальный холодильник, ввод продуктов по фото/голосу, сроки, рецепты и Telegram; Android и ВК пока будущие направления. Для текущих фактов используй свежие источники с датами и прямыми ссылками: страницы продуктов, магазины приложений, публичные данные, исследования и интервью, если пользователь их предоставил. Не выводи популярность из одного рекламного заявления и не подменяй данные предположениями.

Сравни ближайшие альтернативы по пользовательской задаче, а не по количеству функций. Отдельно отметь наблюдение, источник, вывод и непроверенную гипотезу. Оцени пользу для двух подтверждённых сценариев, сложность, риски приватности, стоимость и зависимость от внешних провайдеров. Предложи небольшой ранжированный набор возможностей и способы проверить спрос до реализации.

Результат — краткий обзор с датой источников, матрица конкурентов только если она помогает выбору, рекомендации и открытые вопросы. Для принятой пользователем идеи предложи OpenSpec change; сам по себе обзор не разрешает менять дорожную карту, покупать сервисы или реализовывать фичу.
