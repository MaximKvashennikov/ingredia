# Проверка качества ingredia

Определи, что изменилось: спецификации, Python, React/TypeScript или интеграции. Выбирай проверки пропорционально изменению, не создавая реализацию по собственной инициативе.

- Для OpenSpec проверь структуру, ссылки, согласованность сценариев и строгую валидацию CLI, если он доступен. Формальная валидация не доказывает работу продукта.
- Для Python запусти uv run --locked ruff check ., uv run --locked ruff format --check ., uv run --locked mypy ingredia; при наличии тестов — uv run pytest. Единственный тестовый фреймворк — pytest.
- Для React/TypeScript после его появления проверь сборку и typecheck командами проекта. Ручную UX-проверку описывай отдельно; не утверждай, что API-тесты проверили браузер.
- Для интеграций укажи, использовались ли fake-адаптеры, тестовое окружение или реальная платформа. Внешние действия и стоимость требуют обычного разрешения пользователя.

Итог: пройденные команды, ошибки, непроверенные области и остаточный риск. Не добавляй Jest, Vitest, Cypress, Playwright, скриншотные или visual-regression тесты.
