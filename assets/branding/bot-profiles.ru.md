# Описания ботов ingredia

Обновлены и проверены через Telegram API 2026-10-30.

## @ingredia_helper_bot

Короткое описание:

🧊 Ваш холодильник в Telegram. Добавляйте покупки по фото или текстом и держите список продуктов под
рукой.

Приветственное описание:

🌿 ingredia — ваш виртуальный холодильник.

📸 Пришлите фото покупок.
✍️ Или напишите список своими словами.
✅ Проверьте продукты и подтвердите добавление.
🧊 Смотрите запасы, количество и известные сроки годности.

Нажмите «Старт», чтобы открыть меню.

## @ingredia_admin_helper_bot

Короткое описание:

🛠 Управление ingredia: поиск пользователей, карточки аккаунтов и контроль доступа. Только для
администраторов.

Приветственное описание:

🛠 ingredia · панель администратора

👥 Просматривайте список пользователей.
🔎 Находите аккаунты по имени или ID.
👤 Открывайте карточки и проверяйте статус.
🔒 Управляйте доступом с указанием причины и подтверждением.

Доступ только для назначенных администраторов.
Нажмите «Старт», чтобы открыть меню.
