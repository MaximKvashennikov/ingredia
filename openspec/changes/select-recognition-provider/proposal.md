# Proposal

## Why

Пользователь хочет заменить распознавание GLM на Qwen через Groq, сохранив GLM для возврата
и не переписывая Telegram, подтверждение покупок или хранение.

## What Changes

- Отдельный адаптер Groq/Qwen для фото и текста.
- Выбор провайдера через AI__PROVIDER и отдельные секреты.
- Общие wire-схемы и ограниченный HTTP-транспорт без связи одного провайдера с другим.
- Общие промпты и неизменный доменный результат.
- Явная ошибка конфигурации без скрытого fallback и без включения оплаты.

После первоначального отказа регистрации пользователь предоставил рабочий ключ Groq.
Подключение активировано; реальные квоты и качество требуют отдельной проверки.

## Capabilities

### New Capabilities

- recognition-provider-selection: явное переключение фото/текста с сохранением GLM.

### Modified Capabilities

Нет: основное поведение холодильника и доступа не меняется.

## Impact

Settings, composition root, два адаптера, общие структуры протокола и тесты.
Схема БД и пользовательский процесс подтверждения покупок не меняются.
