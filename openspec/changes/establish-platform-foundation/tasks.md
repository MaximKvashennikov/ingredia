# Tasks

Реализация разрешена 2026-10-30. Начата первая часть; задачи отмечаются завершёнными
после выполнения всех критериев, а не по наличию базового кода.
Фактический статус: docs/telegram-foundation.md относительно корня проекта.

## 1. Основа и границы доступа

- [ ] 1.1 После определения продукта и доступа закрепить версии runtime, uv-окружение и структуру
      FastAPI/Telegram; проверка: чистая установка по lock-файлам, проверка импорта приложения и
      запуск pytest.
- [ ] 1.2 Реализовать контракт идентичности и проверки прав из отдельного change доступа; проверка:
      pytest для отсутствующей идентичности, чужого ресурса и разрешённой операции.
- [ ] 1.3 Зафиксировать схему API подключений и единые безопасные ошибки; проверка: pytest
      соответствия ответов схеме и отсутствия секретов.
- [ ] 1.4 Реализовать версионируемый OpenAPI-контракт и общий principal клиентов; проверка: pytest
      схем, совместимости ответов, пагинации, идемпотентности и одинаковых прав независимо от
      способа входа; Android не разрабатывается.
- [ ] 1.5 Подготовить Dockerfile для API/worker и обоих ботов, Compose-конфигурации для локального
      запуска и первого сервера с PostgreSQL; проверка: `docker compose config` , чистая сборка и
      запуск, pytest на PostgreSQL, сохранность данных после пересоздания контейнера, отсутствие
      секретов в образах и внешнего доступа к БД.

- [ ] 2.2 Реализовать реестр и контракт адаптера с тестовым провайдером; проверка: pytest для

- [ ] 2.3 Реализовать проверку, включение и отключение подключения; проверка: pytest всех переходов

- [ ] 2.4 Реализовать безопасное хранение и замену секрета; проверка: pytest успешной/неуспешной

- [ ] 2.5 Реализовать идемпотентность изменяющих API-запросов; проверка: pytest повторного ключа с

- [ ] 3.2 Реализовать выбранный транспорт и проверку подлинности; проверка: pytest
